## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on malik-na/maclab, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five-label vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
